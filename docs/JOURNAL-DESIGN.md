## 2026-10-15 [DEBUG] Таймер «next run» показывал 0 в первую секунду минуты (задеплоено `1bb1002c`)
- Симптом: hero «00:00» и плавающая кнопка «next run 0s» сразу после прогона.
- Причина: `useNextRun` считал `Math.ceil(60 - intoMinute)`, что даёт 60 всю первую секунду; потребители брали `% 60`, получалось 0.
- Фикс: `secondsLeft = 59 - floor(intoMinute)` (всегда 0…59), `% 60` убран из `hero.tsx` и `sticky-cta.tsx`.
  Первый вариант `floor(60 - x)` отловлен на ревью: при x = 0 давал 60.
- Проверка: tsc 0, lint 0; локальный превью, 70 с через границу минуты: все 60 значений 00:00…00:59, посторонних нет.
